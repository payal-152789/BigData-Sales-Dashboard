# Big Data Sales Analysis Dashboard
**Developed by Payal Amale**

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Start Streamlit:
   `streamlit run app.py`

## Deploy on Streamlit Community Cloud
1. Upload `app.py`, `requirements.txt`, and `sales_dataset.csv` to a GitHub repository.
2. Open https://share.streamlit.io/
3. Select the repository and set the main file path to `app.py`.
4. Click Deploy.

The dashboard uses a generated sample dataset for demonstration. It supports uploading another CSV with `Sales`, `Category`, and `Region` columns.
